# Quran Connect Dashboard

A production-ready Quran Academy Dashboard featuring dedicated role-based portals for Admin, Teacher, and Student management.

---

##  Project Overview & Roles

This dashboard streamlines academy management, class scheduling, and student progress tracking through 3 distinct portals:

*  **Admin Portal:** Manage student/teacher enrollments, trial requests, contact inquiries, course catalog, testimonials, and academy settings.
*  **Teacher Portal:** View daily/weekly timetables, launch live classes (Zoom/Meet), track assigned students, log lesson progress, and update profiles.
*  **Student Portal:** Access live class countdowns, view enrolled course syllabi, check weekly schedules, view teacher profiles, and track learning progress.

---

##  Tech Stack

* **Frontend Framework:** React 18 with TypeScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Routing:** React Router v6
* **Notifications:** Sonner

1. **Clone the repository:**
   ```bash

   cd quran-connect-dashboard
   npm install
   Create a .env file in the root directory:
